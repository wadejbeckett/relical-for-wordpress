# Relical for WordPress

A WordPress plugin that backs up a site, restores it and moves it to another address or host. It installs like any other plugin, on any host, and needs no control panel, account or outside server. Part of the Relical backup suite.

- A backup is kept on the site first. SFTP, S3-compatible storage and WebDAV are built in as further destinations.
- Every run makes a complete backup that restores on its own, and stores only what changed since the run before.
- Every backup is encrypted.
- Sites can be exported to, and imported from, All-in-One WP Migration's `.wpress` files.
- Free and open source, with no paid tier and no feature held back.

## Status

In planning. No code has been released yet. The first step is a set of lab tests of the storage format and of the parts that have to work on every host.
